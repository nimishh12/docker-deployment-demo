# Docker Images and Deployment of Containerized Applications

## Aim

To create Docker images and deploy containerized applications using Docker.

## Technologies Used

* Python
* Flask
* Docker
* GitHub

## Project Description

This project demonstrates a sample Flask web application configured for Docker containerization. The application provides a home route and a health-check route.

## Project Files

* `app.py` – Flask application source code.
* `requirements.txt` – Python dependencies.
* `Dockerfile` – Instructions for building the Docker image.

## Expected Output

The application displays a success message when accessed through the home route and returns an OK response through the health-check route.

## Status

Project files uploaded to GitHub. Docker image building and container deployment are pending verification.
